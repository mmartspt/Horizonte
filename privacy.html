PRIVACIDADE

Política de privacidade

Esta página apresenta a estrutura inicial da política de privacidade do HORIZONTE. Antes de o website recolher dados pessoais, formulários, analytics ou outros serviços de terceiros, esta página deverá ser atualizada com informação específica sobre esses tratamentos.

Dados

A versão atual do website não inclui um formulário próprio de recolha de dados nem uma base de dados de utilizadores. O botão de partilha utiliza as funcionalidades disponíveis no navegador ou no dispositivo.

Serviços externos

As ligações para redes sociais direcionam o visitante para plataformas externas. Essas plataformas têm as suas próprias políticas de privacidade.

Contacto

Quando existir um endereço oficial de contacto do HORIZONTE, esta secção deverá ser completada.
